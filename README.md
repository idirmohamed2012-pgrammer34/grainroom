# Grainroom — Free Photoshop Online

Free browser-based photo editor with real layers, masks, clone stamp, healing brush, adjustments and export.  
No signup. No watermarks. 100% client-side.

**Live:** https://grainroomapp.vercel.app

## Features

- Layers + many blend modes
- Layer masks
- Clone stamp & spot heal
- Magic wand + selections
- Non-destructive adjustments
- Text & shapes
- Free Transform (Ctrl+T)
- Export PNG / JPEG / WebP
- English + French landing pages
- Fully offline-capable once loaded

## Deploy

This is a pure static site. Just push to GitHub and connect to Vercel.

```bash
# or
vercel --prod
```

## Analytics

Vercel Web Analytics is already included in all pages (`/_vercel/insights/script.js`).
