Convert image to Base64

Embed small images directly in HTML or CSS. Get a data URI, an img tag, a CSS background rule or the raw Base64 string.

✓ Free✓ No upload

How to use it

  1. Drop an image on the box above.
  2. Choose the output style.
  3. Click Copy.

Frequently asked questions

Is my file uploaded?

No. Everything is processed on your device by your browser. Nothing is sent to a server.

When should I use Base64 images?

For very small images such as icons, where saving an extra request helps. Base64 makes data about 33% bigger, so large photos are better as normal files.
